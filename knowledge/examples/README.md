# Worked board examples

Two real boards, both run through `scripts/visual_check.py`, kept because a rule
is easier to follow from an example that passed than from a paragraph.

## storyboard_PASSING_EXAMPLE.json

Produced in the first Phase 3.7 to 4.5 dry run, from the producer's "ten day
chute" plan. Clears all 16 rows: 24 visual events over 60s against a bar of 18,
longest hold 5.0s, zero percent talking heads, four sight gags across four
shots, and a world whose name is built from the story's own nouns.

Read it for the SHAPE of `visual_contributes`. Every one of them names what the
picture knows that the line does not, and none of them describes the picture
again. That field is where a board is really graded.

## storyboard_FAILING_EXAMPLE.json

The failure the owner named: two figures, one Alaska break room, nothing
happening. Eleven red rows, including motion energy 0 per 60s, one held frame of
56s, 100 percent talking heads, and the Alaska shelf guard firing on 'alaska'
and 'snow' with no counterpart in the story.

This board would have shipped before the gate existed. Keep it as the thing the
gate is FOR.
